这是 JSON 工具的原理示例。一段合法 JSON 可以包含超出 JavaScript 安全整数范围的数字。

## 一个容易忽略的边界

```json
{ "id": 9007199254740993, "ratio": 1.234567890123456789, "scale": 1e1000 }
```

如果把解析后的数值对象重新序列化，数字的表示和精度可能改变。仅仅为了缩进，不应该付出这个代价。

## 只修改空白

先完成严格语法校验，再对文本空白进行编辑。压缩时同样保留字符串和数字 token，不用数值对象重新生成结果。

## 自己试一下

在 [JSON 工具](/tools/json/) 中粘贴上面的内容，格式化和压缩后，数字文本应完整保留。注释、尾随逗号和不完整的值会得到错误提示。
